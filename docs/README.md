# docs/

| Path | What goes there |
|---|---|
| `adr/` | Architecture Decision Records: one decision per file, numbered, never rewritten. Superseded ADRs get a new ADR that points back. |
| `projects/` | Product/project specs: requirements, architecture, gates, risks. |

ADR template (copy into `adr/NNNN-short-title.md`):

```markdown
# NNNN: Title
- Status: proposed | accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context
## Decision
## Consequences
```
